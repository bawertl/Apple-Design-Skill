## ✨ About This Project

**Apple Design – AI Skill** is a freely accessible community backup of an existing `SKILL.md` for fluid, responsive and polished web interfaces. It brings together design concepts discussed in Apple WWDC sessions and practical guidance for AI-assisted UI development.

The goal is simple: **preserve useful design guidance and make it easy for the community to find and reuse.**

> [!IMPORTANT]
> This is an **unofficial community mirror**, not an Apple product or official Apple design guide. It is not affiliated with or endorsed by Apple or the original project.

---

## 🎨 What Is Included?

The [`SKILL.md`](./SKILL.md) covers **17 design topics**:

| # | Design topic | # | Design topic |
|---|---|---|---|
| 01 | Immediate response | 10 | Gesture details |
| 02 | Direct manipulation | 11 | Frame-level smoothness |
| 03 | Interruptible animations | 12 | Materials and depth |
| 04 | Spring-based behavior | 13 | Sound and haptic feedback |
| 05 | Velocity handoff | 14 | Reduced motion and accessibility |
| 06 | Momentum projection | 15 | Typography and spacing |
| 07 | Spatial consistency | 16 | Eight design foundations |
| 08 | Gesture direction hints | 17 | Interactive prototyping |
| 09 | Rubber-banding | | |

The skill includes explanations, implementation suggestions and code examples, with a primary focus on **web interface design**.

---

## 🚀 How to Use

1. Open **[SKILL.md](./SKILL.md)**.
2. Read the file or provide it to your AI coding assistant when designing or reviewing an interface.
3. If your assistant supports reusable skills, place the file in its supported skill directory.
4. Apply the principles and test the actual behavior on your target device.

**Note:** A `SKILL.md` is design guidance. Simply downloading it does not automatically install it in every AI assistant.
