## ✨ About This Project

This repository preserves a copy of the **Apple Design** `SKILL.md` originally created by **Emil Kowalski**. It translates ideas discussed in Apple's WWDC design sessions into practical guidance for creating responsive, fluid and polished web interfaces.

The purpose of this repository is **preservation and easy access**, not to claim authorship of the original material. The skill is shared free of charge for the community.

> [!IMPORTANT]
> This is an **unofficial community backup**, not an Apple product or an official Apple design guide. The original skill belongs to its author, **Emil Kowalski**. This mirror is not affiliated with or endorsed by Apple or the original author.

---

## 🎨 What Is Included?

The [`SKILL.md`](./SKILL.md) covers **17 design topics**:

| # | Design topic | # | Design topic |
|---|---|---|---|
| 01 | Immediate response | 10 | Gesture details |
| 02 | Direct manipulation | 11 | Frame-level smoothness |
| 03 | Interruptible animations | 12 | Materials and depth |
| 04 | Spring-based behavior | 13 | Sound and haptic feedback |
| 05 | Velocity handoff | 14 | Reduced motion and accessibility |
| 06 | Momentum projection | 15 | Typography and spacing |
| 07 | Spatial consistency | 16 | Eight design foundations |
| 08 | Gesture direction hints | 17 | Interactive prototyping |
| 09 | Rubber-banding | | |

Topics include explanations, implementation suggestions and code examples. The skill focuses primarily on **web interface design**.

---

## 🚀 How to Use

1. Open **[SKILL.md](./SKILL.md)**.
2. Read or provide the file to your AI coding assistant when designing or reviewing an interface.
3. If your assistant supports reusable skills, install the file using that assistant's documented skill-directory structure.
4. Apply the guidelines to your own project and test the actual behavior on your target device.

**Note:** Downloading or referencing a `SKILL.md` does not automatically install it in every AI assistant. Support and installation steps vary by tool.
