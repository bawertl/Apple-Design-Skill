# Apple Design Skill — Community Backup

An independent, publicly accessible backup of the **Apple Design** AI skill written by **Emil Kowalski**. It summarizes interface-design principles and fluid interaction patterns from Apple's WWDC design sessions and translates them into practical guidance for web development and AI-assisted UI work.

## What's inside?

The `SKILL.md` covers 17 areas, including immediate feedback, direct manipulation, interruptible animations, springs, gesture velocity and momentum, spatial consistency, soft boundaries, materials and depth, haptics, typography, accessibility, Apple's eight design foundations, and iterative prototyping.

## Using the skill

Read [`SKILL.md`](./SKILL.md) as design guidance when building or reviewing user interfaces. For an AI coding assistant that supports skill files, add this file to the appropriate skill directory following that assistant's installation instructions.
